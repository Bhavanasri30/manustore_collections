# manu_stores25

A responsive frontend-only fashion storefront built with React, Vite, Tailwind CSS, React Router, Context API, Recharts, and localStorage.

## Features

- Owner signup and login
- Customer signup and login
- Product catalog with search, filters, and stock states
- Product detail pages
- Cart and checkout flows with local order generation
- My orders and tracking
- Owner dashboard with sales metrics and product management
- LocalStorage-based persistence for products, cart, orders, and returns
- Floating chatbot for product and order guidance

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal, usually:

```bash
http://localhost:5173
```

## Build

```bash
npm run build
```

## Notes

- This is a frontend-only demo without any backend or database.
- The app stores data in browser localStorage and is designed for demo and learning use.
